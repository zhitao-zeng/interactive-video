# 互动剧声音与指定场景文字（2026-10-14）

笑之国旧版的原稿提到低位音乐，H3编译器却固定写`non_diegetic_music: None.`，SD编译器固定写“无背景音乐”。知遥26条台词用了同一段泛化语气说明，多数其他台词仍按场景批量使用同一种语气。指定告示牌与通用“禁止任何文字”也冲突。这些是已定位的输入问题；不能因此断言模型声音表现只由这些因素造成。

现有`audio_plan.music_cue`逐镜交给两种模型。打包保留`music_cues`，H3一次成稿中单独翻译音乐，物理声景与音乐分开；更改音乐会使其旧翻译失效。SD保留阶段音乐说明；没有配乐说明的旧输入仍保持原默认。两种模型继续使用原生角色对白，声线参考只约束人物音色，逐句`emotion`提供当下的重音、呼吸、节奏变化和句尾处理。

已批准的导入分镜可用`native_text`列出实体牌面、纸张或屏幕的确切文字。SD编译只允许这些实体表面的文字，不再同时禁止全部文字；对白字幕仍由实际语音时间对齐原计划台词。未放开H3已有的“中文只能在对白内”检查，也未声称H3原生中文已修好。

本次独立SD480版沿用笑之国59镜、31组、292秒、三声源及原台词，人物与声线参考从现有H3资产复用。新增规则牌标题“笑之国法律”来自本轮用户明确要求。后期场景贴字、色块遮盖和预览标签仍关闭，仅保留对白字幕与片尾3秒完整选择卡。配乐和动作声交给模型原生生成，不用配乐去伪装静音指标或替换自然语气。

共用素材登记另有真实失败：长edition使素材名称超出服务数据库范围；原图下载到素材库时超过服务自带期限；刚登记的素材仍在Processing，却提前用于视频请求，实际返回“asset is still processing and is not available yet”。登记名称保留已有内容后缀并缩短前缀，名称冲突兼容服务实际返回的HTTP409。大于2MiB的公开传输副本沿用既有上传的1280长边JPEG处理；原图、比例、旧引用及历史不变。传输缩小不能证明远端下载稳定。

新登记和已有未确认的素材编号经GetAsset就绪检查后才能进入视频请求，沿用既有poll_timeout与请求时限；Active缓存继续复用，处理失败保留编号和错误，不盲目重复登记。未增加超时或重画。匹配输入但仍缺段的resume必须先回原渲染器续取任务和补缺，再进入内容修复；不能因报告指纹匹配而只审空缺、不再生成。
