## KEY和共享范围

配置只存变量名。密钥值继续保留在原私有.env／登录文件，不复制到代码、报告或日志，私有额度状态按实际token身份隔离，避免每次准入都向平台查token身份；该本机标识不进入日志、报告或Git。同一token跨项目共享停机，不同token或换key不继承旧停机。

- `PHANTHY_API_KEY`：本地8789的访问凭据；服务内部复用Phanthy OAuth。零费率和计费模型都可由同一key访问，不能按key一概认定免费。
- `PHANROUTER_API_KEY`与`PHANROUTER_SD25_KEY`：本次内存比较确认相同，登记为同一token组。
- `PHANROUTER_IMAGE_API_KEY`与`PHANROUTER_H3CLOUD_API_KEY`：本次确认相同；图片、SD2.0、云H3和official文字调用登记为该token组。
- 将H3cloud等变量换成不同key后，运行时会按实际凭据比较隔离其未确认token组；不同key不证明不同账户，不能把余额相加。
- 两把云端token均实查到`unlimited_quota=true`、`expires_at=0`。这是token自身没有限额／到期时间，不证明账户总余额无限，更不证明模型免费。接口中的负`total_available`不作为现金余额解释。
- 不在登记表中的显式JsonEndpoint key不会套用另一把已登记key的停机记录。
