## 修改

- FastH3：显式填写 purposes 时，把真实图序及用途说明发送到模型并保存在 wire；不填时保留原 Prompt 直传行为。用途说明不是身份锁。
- 云 H3：first_frame 仅为普通参考，不再在提示词或返回值声称绑定了 t=0；本地 H3 与 SD 真首帧语义保留。
- Pi 专用 H3/声音参考覆盖旧宿主说明，明确 Agent 自写完整 Prompt，不依赖结构化对白、情绪插入或自动配音。保留官方原文及旧宿主资料。
- Skill 区分稳定身份和本镜朝向/站位；按问题选择综合卡或单幅，不强制单人、逐镜首帧、拆镜或新检查阶段。摘要使用简短英文，不复述对白；英文被误念是风险而非必然规律。
