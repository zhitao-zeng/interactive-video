## 节目概念

四位成年人匿名聊了七天，见面前收到一朵未署名的花。她先问错了送花的人，真正的笔友随后接上昨晚的细节。认出以后，新的吸引仍然可能发生。

宣传句：**你会把今晚的花，送给谁？**

四种花是节目原创的邀约语言，不是人格测试，也不声称是传统花语。任何嘉宾可选择任何一种花，也可不送；收花代表收到邀请，回应才决定是否赴约。

|花|节目内的邀约意思|
|---|---|
|栀子|先一起坐一会儿，继续聊|
|玫瑰|我想单独认识你|
|鸢尾|有件事想当面问清楚|
|向日葵|明天一起做点什么|

## 风格与空间约定

使用现有weimei.json的乙女游戏过场动画质感半写实三维CG；source_en保持原文。人物单图仅定外形，不继承站姿或灰背景；空房参考仅定建筑家具，不新增嘉宾。这一视觉类别是唯美CG恋爱节目。

四椅世界归属：阮夏NW、程越NE、闻屿SW、许棠SE。北墙行李西至东：阮夏奶油、闻屿炭灰、程越橄榄灰、许棠焦糖。北西门、北东吧台、东窗、西墙展示轨和单张茶几固定。画面左右随机位改变，不能拿屏幕左右重排座位；画外仍在场。

静态参考由Agent实际看图通过：四人经过两轮画风编辑，温室一轮；摄影感初图只留运行记录，不进入采用素材。四种花单支参考亦由Agent审核通过。

首拍经既有自动审查放行，但独立Agent发现两段西侧错座、第二段构图未执行及行李位新增白花。经保留预算与历史的Agent请求修复，F01第2take、F02第3take已接受；第二段使用同一温室东向西空场参考，人物仍在原世界座位。最终27.56秒小样的画面和新增后期经Agent复审通过，成片技术门通过；一处姓名条位置属非阻塞建议。最终结论见delivery.json。
