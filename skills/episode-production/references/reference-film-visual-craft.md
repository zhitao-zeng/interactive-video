# 从20部原片取用画面组织方法

用于选美术、构图、调度和剪辑时遇到的具体问题，不是五道制作关卡，也不要求每镜填写下面所有内容。当前任务允许重写时，画面设计可以反过来改变事件、人物分工和叙述顺序。先选本片值得看的东西，再按需要借方法；不要把20种作品磨成一种“电影感”。

## 审美：媒介、材料与生活关系一起成立

风格不只是配色词。想想人物和物件是什么做的、表面保留什么、怎样受光、动作适合什么形体。08《地牢酒馆01》有多边形明暗块和低清木石贴图，属于复古3D游戏语汇，不是实体黏土。18《寺虎》的木雕切面、红颊、雕刻胡须和纺织粗纹接近民间造像；脸部幅度有限时，转身、端烛、抬石和接触仍能把行为讲清。两者不能用同一串“细腻皮肤、高模毛发、无瑕写实”覆盖。

大面积底色、少量强调色和明暗可以安排注意。08用灰肤、褐木铺底，交接处的钱袋与金币点黄；11《梦的游牧》把灰蓝建筑、深绿地面与一个暖入口区分开。颜色的作用来自面积、位置和当前事件，不是冷色永远危险、暖色永远安全。18的暖烛光同时照亮招待和误读。

05《千灯集市》的奇异生物与行人共用日光街路，不靠每人惊呼证明奇观；住、走、运货的关系使世界像已有生活秩序。不能见灯笼就改成夜景霓虹。01/07的生活邀请、06/11的巨构、14的料理过程、16/19的行动场面需要不同的美术重心；从眼前作品选媒介，不把片名或作者名当材质证明。

身份与状态也可由画面分离：03暗树林前的灼红掌心让受伤有具体位置；16的红衣、白袍、金甲与器物轮廓让三人同框仍分得开。色彩先帮观众认人、看接触和变化，不必把每个角色都涂成相同的环境主色。

## 构图：让观众有地方站，也有东西可比较

画面最想让人看懂的关系，可以通过大小、遮挡、明暗、疏密和清晰度来组织。08中近处店员手、稳定桌沿与后方巨人的胸腹、手掌同框，钱袋放到两者之间；巨人之大有可比较的尺度，交易也有接触位置。05的近伞、檐口、栏杆和行人让街景可进入；只有精密远景，观众容易像在翻景观卡。

11末镜把平缓水面、草地留在前中景，密集窗格退后，小人物提供尺度，一个暖入口集中视线。不是每层都同样满、同样锐。14以黑锅围住浅色食材和白奶流，橙火、暗绿交代现场；倒入、稠化和勺起的接触比背景装饰更值得看。需要亲近关系时，局部接触与身体距离可能比宏大环境更重要。

可以让遮挡控制揭示，也可让画面一开始就坦白。门、窗、枝叶的作用取决于挡住了什么、何时出现；不为了构图装饰遮掉关键动作。素材图的全场人物清单不等于这镜都该露面，近景与反打可用局部保留空间关系。

## 镜内调度：安排谁在做事，何时轮到观众看见

14开头前景主播持续讲解，后景同伴突然倒下；稳定讲解和突发身体反应同时存在，观众先于主播察觉。若借这种双层活动，后景动作、人物间距离与清晰度要足以读到，浅景深不能把笑点虚掉。若想让观众跟角色同时发现，就用遮挡、转眼或机位重新分配信息；这会改变笑点与紧张来源。

04《异世界酒馆Vlog1》首口食物前后靠近脸部读试探与满足，饮料后的翻滚需要拉开容纳身体，再靠近读请求。景别服从当下需要看的身体部位，不按全景/中景/近景轮流打卡。08先让武器、肚腹进入再露脸，钱袋填到人手之间，观看从可能冲突转到服务需求；入画顺序本身就在讲事。

15《感染区》的乘客与窗外共框，窗框同时是身体参照、保护边界和揭示框，近掠的东西因此有接近对象。相机、人物和环境可以分别运动；不要把所有变化都叫运镜。可以保持观察，让动作穿过画面，也可随人物移动，但运动应让关系更可读，而不是不断抢走观看对象。

10《特安局POV》在一个连续外观段落里，先让爆炸与奔马被读到，再向右越过烟雾、柱子，随后才露出同伴，前景持枪手保留观看者的位置。揭示的等待发生在镜内，不一定靠加一次剪切。20拉开冰箱时保留门架，异域市场从门里显露，再用脚跨过同一门槛兑现进入；门前、门后两张好看的背景不能自动代替这个空间接缝。

## 镜组衔接：保留一条关系，改变下一次看见的东西

相邻镜头可以由视线、动作、形状、亮区、方向、物件状态或声音建立联系，不必每次换地点就重新讲解。11前四镜在共同尺度规则下变换轮廓与观察位置，第5镜减纹理、集中中央光束，第6镜接住竖向亮区再恢复住宅细节；疏密与形状构成变奏，比每镜同样复杂更能组织观看。

14先转眼与惊讶，再经叶片遮挡揭出食人花，让反打回答刚建立的问题。需要同时看动作和回应时可同框；需要延迟对象或突出局部结果时可切开。拍完接触再给对方反应，或先给反应再揭对象，改变的是观众获知顺序，不只是景别。

操作组接可选“对象原态—有用的接触—可辨的改变—使用或反应”，不要求全拍工序。14的材料、加工、鼻前使用和睁眼能接成用途；04的手部劳动与整栋木屋交替，把省略过程接到空间成果。02转阀、升水、乘鸭、够梯子的对象和前后条件相连；只换几个奇景不能代替这条行动链。跳过路程或重复劳动可以成立，但不要把决定动作、关键交接或因果结果顺手剪没。

屏幕左右不是固定世界坐标；换观察位置时，让关键人物、行动方向和持有物仍可追踪。18井边由身体动作、俯看、井下仰看、虎与退让组成视线链，能增强确信，但不会把讲述者的版本变成独立事实。镜间相邻也不自动证明人物互通消息。

## 节奏结构：段落换功能，观看速度才有变化的理由

04前约40秒留给取食、反应与请求，建设约11秒密切17镜，最后回到稳定购物视点。可借的是“看反应—压缩已理解的劳动—停下感受结果”，不是17镜的数字。短镜并不自动更有戏，长镜也不自动更高级。

08前两位顾客让观众学会服务程序，第三位通过钱袋、肉和桶改变尺度与期待。同一柜台可以重复，只要下一次观看有区别；不是每轮都再解释同一规则。15在身体距离的威胁、群体、建筑系统与居住空间间换尺度，再回到近身距离，观看任务在变化，即使不密集切镜也有节奏。

14把救助的紧凑、料理工序、舀汤与进食的感官停留交替，后段海边饮料另起小篇章。17多线切换能暂存疑问，也会让人物危机等太久；19较慢的犬只回忆改变救助的情感意义，不能仅因慢就删。05/12不断换景能提供发现感，却不自动累计到达感；若本片要一条旅程，可让地点、同行者或物件承接，若本来是图卷则保留浏览价值。

判断停留时，留意观众仍在等什么、材料/身体/关系或空间发现是否还在变化。可以让动作落定后留反应，也可以在未完时切走制造牵挂；切走要知道暂存的是什么，回来的信息是否值得等。选择更快、更多遮挡、更强冲突，都有损失；没有统一镜长、固定快慢比例或每片必用的三段式。

## 用于实际请求与边界

把选中的关系落实为实际画面：谁相对谁有多大、哪层动作必须可读、观众先见什么后见什么、相邻镜头承接哪一个状态。图像请求只需本图成立的构图与状态；视频请求描述由此发生的动作、注意转移和结果，不把整段剪辑说明塞进一张首帧，也不把媒介选择与相反的公共后缀拼接。

- 无手部剧情时，POV 默认完全省略主角自身身体描述，不逐镜重复手可入镜。必要手部动作须
  有明确叙事目的，写清起止和完成后退出；持续露手不是第一视角的成立条件。
- 光影、反射和线条只在引导注意、交代空间或状态、揭示线索等叙事用途中保留，不把光斑、
  网状线或装饰线条当作默认电影感。参考图制作与 H3 检查都要核对实际附件及当前视频；
  异常光斑、网状线、扭曲几何和非预期运动模糊是实质视觉问题，不能因故事或台词正确而
  判为 `accepted`。

例子来自用户20部原片的既有抽帧研究、V2报告和本次选段核对，不是作者原始prompt或制作流程。原片声音专项听审未完成；上述视觉节奏不能冒充音乐、表演或声画同步结论。20片是不同作品的可选经验，非统一配方；实际生成是否实现，要看当次输出。[成片反馈](director-feedback.md)用于定位偏差与修法，不要求新增一轮制作或审核。
