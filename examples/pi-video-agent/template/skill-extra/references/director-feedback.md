# 导演表达与基于成片的修改

把本页当作创作和判断的参考，不是镜头必填表或新的生产阶段。任务决定剧情、对白、规格和预算；具体镜头、模型、首帧、工具和修法由你选择。

原剧本可以是改编材料。当前任务未保护的情节、台词、人物功能和顺序允许重写；下文案例中的“原剧情”指当次要求保留的意图，不把旧任务的逐句忠实要求沿用到允许大改写的新任务。故事或人物行为本身失效时，先取用[写戏机制](reference-film-craft.md)改设计，不要只靠润色对白、追加运镜或重复生成来补。

## 让意图变成观众能看到的变化

对关键事件，说明观众需要理解什么，以及哪一个动作、物件变化或人物反应承担这个信息。把“紧张、感动、有电影感”落实为可见、可听的表现；普通承接镜头不必为填模板增加动作或运镜。

例如，人物“第一句写不出来”时，笔悬着、看纸、停顿后决定落笔，比“一边说写不出一边持续写字”更清楚。EP09A 的最终落笔段保留了这种迟疑与改变，慢下来有心理内容；它不是应按静音比例自动剪掉的空档。EP08B 的归还手续之后，红灯变暗、出口出现，也让规则后果有了画面证据。

W24 的救羊段用沟底、沿光照缓坡移动和到达高处的前后画面，让救援结果成立。完整攀爬过程可以省略，只要关键空间与因果仍可理解；不能仅因省略过程就判瞬移或要求重拍。

切点应保护本镜承担的动作结果和反应。移动一个插入镜前，查看其中是否还包含“按停止”“交出物件”等改变事件状态的动作。EP09A 为先展示煎蛋而前移了包含按键的镜头，削弱了“回忆触动她，随后决定停止”的因果。可以只选适合前移的画面，把决定动作留在其应发生的位置。

## 用画面关系表达美术，按需要挑选描述

具体的媒介/材质、主次与尺度、同框活动、形状与亮区接力、段落换挡，以及地牢酒馆、梦的游牧、料理等原片例子，统一放在[20片视觉方法](reference-film-visual-craft.md)。本页保留实际成片偏差的判断与修法，避免同一条视觉经验在两页各写一套。

偏差需要修时，先确认影响的是观看重点、身份/物件区分还是故事后果，再选必要的表达；不为追逐“电影感、8K、极致精美”改坏已经成立的画面。关键主体靠形态、位置、持有或行动区别，不能只靠“都是发光物”。

## 参考与首帧服务于具体问题

首帧可帮助固定关键空间、人物关系或动作起态；已有角色/场景参考足够时，也可直接生成。用代表性结果判断是否值得扩大同类请求，不默认每镜都生首帧，也不固定试拍张数。

附件路径和传输正确，不代表实际图里存在你写的主体。引用“首帧中的某物”前，以实际所见核对它的形态、位置和归属。首帧应承接本镜的真实起态：既不要提前完成后续动作，也不要把前镜已完成的状态倒退；镜内后入画的人或物可以在视频中出现。

人物身份与本镜调度分开：同一张脸、衣装和声线可以复用，面向镜头、背对镜头、处于前景还是画外要由当前镜头决定。越肩镜写清肩膀属于谁、镜头朝向谁；全程第一视角的主人可以只出现手或声音，不要求再把他的全身放进画面。需要倒影或同一人物的多个影像时说明其来源，不把正常双人构图一概禁止。

综合角色卡可帮助你理解角色；视频附件按当前需要选。多视图、表情格、文字和灰底也在实际图片里，可能侵入画面。发生复制或卡片侵入时，可以换成相关单幅或裁出需要的视图，并在正文绑定用途；这不是要求每镜重建参考图。S2E10B 的越肩拍照镜曾复制知遥，原 Agent 改成单人背后三分之四后通过，仍用了相同附件；这支持澄清构图的做法，没有分离证明某句话或综合卡是唯一原因。S2E08C 也在已绑定身份、人物和空场参考时出现复制，正确输入仍可能产生模型失真。

相似对象要有观众能辨认的区别。例如 W24 中，小月亮是会自主行动的角色，引月灯是人使用的工具；形状、提把、持有者、位置或运动方式应让两者可区分。实际首帧曾把球体画成另一弯月牙，视频请求却仍指称“图中的发光球体”；另一些正确月牙灯又在视频里变成圆球。这包含起态、指代和模型执行的不同问题，不能统称“模型不听话”，也不能靠再加一句“禁止运镜”解决。

批量使用共同写法前，关注会扩散的身份、衣装和关键物件表达是否在实际结果中成立。W24 的一批衣装返工同时补写了现代衣装事实和排除描述，作者随后观察到改善；这次结果没有分离各句修改的贡献。稳定风格与身份可共用，本镜状态、持有关系、光线和动作应按当前情境写清。

## 看实际采用的段落，允许证据纠正判断

按观众是否能理解人物、关键事件及其后果判断；你的初稿是方案，不是要求生成器逐字复现的验收答案。合理推近、反打或细微外观变化可以保留；两名不同角色变成同一个人、唯一道具变成两件、决定动作顺序颠倒，会直接改变理解，优先处理。

- W22 在制止商贩和结伴过桥的片段中复制/替换了人物，实际角色附件却正确。请求里写了正确人数、continuous shot，不证明视频执行了它；字幕姓名和完整对白也不能冲抵换人。
- EP08B 的唯一厚书同时出现在知遥与男孩手中，模糊了借出和归还对象。应关注关键物件的实例与持有关系，无需追究所有背景物件。
- EP08B 的红灯在稀疏概览中看似未熄，连续帧却证明已经由亮转暗。抽帧没看见不等于动作未发生；先补看对应前后状态，避免误报引起重拍。

当已发现某种具体故障，例如本次 H3 样本的尾部自切、参考卡侵入或多脸拼贴，把观察位置对准实际保留的尾段、动作转折与相关镜头。按共享素材、人物组合或生成写法判断影响范围；不因此要求每次全片重新审一遍。平滑推近与身份拼贴要分开判断，存疑时看连续帧或单帧细节，不靠小拼图猜测。

## 修改前确认它能改变结果

同一缺陷再次出现时，比较实际发出的请求和回执，不只比较文件名或修改说明。W24 两对 H3 请求仅换输出名，prompt、附件、种子与采样未变；其中输入 5.2 秒仍落在实际 6 秒档位。“缩短了”并没有发生。再次生成应有能改变结果的依据；若选择同条件重采，说明它只是抽样尝试，根据真实结果决定是否继续，不能声称已针对性修复。

可按证据选择更清楚的表达、修正实际参考/起态、合理裁切或拆句、在任务允许时换已验证的模型。保留原始请求与失败结果；不要靠清记录、改名或追加预算制造成功。普通图片参考、first_frame、音频参考是不同条件，复盘时按真实接口角色描述；把画过的首帧图作为普通参考，不等于启用了首帧模式。

## 后期检查对应的最终输出

源 take 正确，不会自动保证裁切、覆图、卡片、字幕和混音之后仍正确。只改画面的处理也可能删掉音轨；补回声音时，画面和音频必须来自相同的原片时间区间。W24 片尾先因覆卡处理丢了对白，补音后又从原音轨 0 秒开始，带回已裁掉的乱语；最终按相同起点裁音频才恢复。

复用现成合成工具与当前采用时间轴，修改后核对受影响区间的真实导出声音和画面。未改部分可沿用仍有效的证据，不因局部修改重复整片生成。不要让旧中间片段配新时间轴，也不要把音轨存在、响度正常或轨长相等写成“对白/口型全部正确”。

自行排字幕时关注实际画幅中的长句。W25试用中，自写ASS即使设置了边距和自动换行，长中文事件仍在导出时被左右裁切；按语义显式分行并看受影响的原分辨率画面，比只相信字号或WrapStyle更可靠。这是字幕用法经验，不要求新增一轮全片审核。

ASR、说话人向量、音高和低电平比例是观察线索。标点或占位 token 的时间不一定是语音结束；裁切还应保护实际句尾、动作完成、人物反应和选项阅读。它们既不能单独判错，也不能反向证明自然、完整或绝无额外语音。无法确认的范围如实说明。

## 反馈和收尾

具体反馈可写成一两句话：**片内时间 → 实际现象 → 对观看/理解的影响 → 最小改法**。区分需要修复、可选提升和未确认项；同时记录哪些表达已经有效，避免改坏。无需为凑数提出问题，也不要求评分表。

已有交付与必要检查成立、没有新的实质问题时就结束；剩余额度是上限，不是待用额度。若确实发现新问题，只处理相应部分，更新最终版本和证据，说明保留或放弃的理由。技术事实交给实际文件/工具计数，内容取舍由你负责。
