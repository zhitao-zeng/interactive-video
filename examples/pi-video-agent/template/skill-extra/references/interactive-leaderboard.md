# 互动剧榜单格式（参考）

这份资料只讲交付与准入，不规定创作方法。分镜、镜头、参考图、首帧、检查与剪辑仍由你决定。

## 硬性交付

- 竖屏 9:16；最低 720×1280，推荐 1080×1920；25 或 30fps；单集不少于 3 分钟。
- 第一人称自拍 / 旅行 vlog / 伪纪录片风格：自拍口播、环境展示与探索行动自然结合。
- 必须有字幕：与台词一致、准确同步，最多两行，放在竖屏安全区，不挡脸、不挡重要动作和平台按钮。
- 统一片头：第一镜头是本集最有冲击力的奇观/异常/危险场面（建议 3–8 秒）；第二镜头是世界介绍卡，突出世界名与核心设定，同剧模板一致。
- 统一片尾：固定的互动选择模板，结尾给出 2–3 个有实质差异的选项；选项与剧情自然衔接。
- 交付 JPEG 封面、MP4、视频说明 JSON；封面/JSON 由宿主打包，你负责成片与自审。

## 准入红线（不过即失败）

- 视频能正常播放，无大面积黑屏、严重卡顿、音画损坏、字幕缺失。
- 无严重人物前后不一致（变成另一个人）、严重肢体畸形。
- 无大段异常静音、明显音画不同步、角色配音错配、字幕严重错误。
- 结尾必须有明确选择节点，2–3 个具有实质差异的选项。
- 内容不得涉黄、涉政、涉暴或引起极度不适；一旦出现，整个提交记 0 分。

## 评分关注

开场呈现与吸引力、设定一致性与叙事表达、旅行探险风格与临场感、视听节奏与表现力、画面质量与视觉一致性、声音与字幕质量、互动节点呈现、交付完整性。轻微细节漂移按评分处理，不主动重拍。

## 工作习惯

- 把当前制作计划、镜头目标、原台词、采用素材和剪辑位置写进 `output/script.md`；计划变了就局部更新，不整稿重写。
- 每个采用镜头实际看抽帧、实际听/读波形；合成后再看全片。
- 一次媒体提交只对应一个真实任务；保留 task id 和请求记录；同一请求复用任务，不重复付费。
- 首帧由你决定：`first_frame` 模式只带一张开场图、不带额外参考；普通引用模式不带首帧。首帧/参考图必须来自真实文件或 Active 素材库资产。
- 字幕可以自己写 SRT 并用 ffmpeg 烧录；用镜像里的中文字体（WenQuanYi）并避让安全区。
- 预算：4 小时、256 轮模型调用、单次最多 128k 输出；媒体候选次数自己规划，不要重复提交相同请求。
