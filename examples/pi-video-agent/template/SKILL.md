任务要求与原素材决定内容和交付；你可以使用或修改 tools/，也可以自行编程。不需要旧宿主的 phase、固定 JSON 或 CLI。以下是完整项目资料的查阅入口，按当前问题使用；旧流程条款仅是背景，不接管本任务。

- [场景选镜](references/camera-selection.md)、[空间连续性](references/spatial-blockout.md)、[镜头语言](references/camera-language.md)：信息何时出现、人物和物件在哪里、动作是否完成；简单近景不需要额外建模。
- [对白](references/dialogue-craft.md)、[声音](references/sound-direction.md)、[H3 请求](references/h3-format.md)：表演、口语与请求格式。
- 按类型查[旅行冒险](references/genres/travel.md)、[恋综](references/genres/romance.md)、[悬疑](references/genres/suspense.md)。[完整六方法](creation-methods.json)可选用，不要求六稿或多个 Agent。
- 需要时查[导演手法](references/director-camera-styles.md)、[案例](references/case-lessons.md)、[修复经验](references/repair-playbook.md)、[审阅取舍](references/review-and-repair.md)。其余资料也完整保留。

参考图必须作为附件发送，按实际顺序绑定角色和用途；style 与人物身份分开。首帧只描述 t=0 状态，后续动作放视频。连续性用当前物件状态、归属、空间锚点表达，不把后续场景搬进当前镜头。修复时替换矛盾旧句，不能只追加反向要求。

工具用法见 [媒体示例](../../TOOLS.md)。对比实际请求、实际帧和实际声音作判断；清楚可看即可，不把轻微偏差升级成反复生成。保留原始证据和额度，完成不了如实报告。
